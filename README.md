# 台灣即時氣象地圖 (Taiwan Weather Map)

中央氣象署開放資料即時視覺化地圖（類 Windy 風格）。

## 專案特色

- **資料庫**：中央氣象署 CWA `O-A0003-001` 自動氣象站觀測資料
- **互動圖層**：
  - 🌡️ 氣溫（彩色漸層標籤）
  - 🌧️ 雨量
  - 💨 風速風向（箭頭及風速）
  - 💧 相對濕度
  - ⛅ 天氣狀態
  - 🔵 氣壓
  - ☀️ 紫外線指數
  - 📍 測站點位
- **底圖切換**：深色模式 (CartoDB Dark)、街道圖 (OSM)、衛星影像 (Esri)
- **資訊面板**：左側即時統計、觀測時間、資料來源與測站總覽
- **自動更新**：每 5 分鐘自動呼叫 CWA API 更新最新觀測數據
- **定位功能**：一鍵定位目前所在位置

## 快速開始

直接開啟 `index.html` 或透過簡易本機伺服器運行：

```bash
python3 -m http.server 8080
```

並在瀏覽器前往 `http://localhost:8080`。
